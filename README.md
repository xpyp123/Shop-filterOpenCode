# ShopFilter

跨平台电商商品聚合搜索与智能筛选工具。支持多平台并发抓取、多维度筛选、综合评分排序，基于 Qt6 + C++17 构建的现代桌面应用。

## 功能特性

- **多平台聚合搜索** — 插件式架构，一键搜索多家电商平台商品
- **多维度筛选** — 按价格区间、评分、评论数、包邮、库存状态精准过滤
- **智能排序** — 内置加权综合评分算法（价格/评分/销量/折扣）
- **多线程并发** — 异步抓取不阻塞界面，实时进度反馈
- **现代化 UI** — 自定义 QSS 主题，清爽简洁的交互体验

## 构建

```bash
# 依赖: Qt6 (Widgets), CMake >= 3.16, C++17 编译器
cmake -B build
cmake --build build
```

## 使用

1. 输入搜索关键词
2. 选择目标平台（可多选）
3. 点击「搜索」并发抓取
4. 使用筛选器精细化结果
5. 按综合评分/价格/销量等排序

## 架构

```
src/
├── platform/          # 平台抓取插件 (IScraper 接口)
├── scraper.*          # 抓取管理器
├── filter.*           # 多条件过滤器
├── product.*          # 商品数据结构与评分模型
├── mainwindow.*       # 主窗口 UI
└── main.cpp           # 入口 + 全局样式
```
